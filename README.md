# Lynceus — Cost-Model-Driven Query Routing for Heterogeneous GPU-CPU Systems

> *"Zum Sehen geboren, zum Schauen bestellt..."*
> — Lynceus der Türmer, Faust II Act 5

Lynceus routes every query to the optimal hardware via heterogeneity-aware
cost models and virtual index recommendations.
